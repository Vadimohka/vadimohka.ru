# Vadimohka.ru

Статический персональный сайт Вадима Владымцева. HTML, CSS и небольшой скрипт мобильной навигации; сборка и внешние шрифты не требуются.

## Структура

- `/` — краткое представление, избранные кейсы, анонс профессионального пути.
- `/projects/` — Century, корпоративная база знаний и прототип персонализации e-commerce.
- `/background/` — работа, академический путь, образование и награды.
- `/approach/` — процесс работы, принципы и компетенции.
- `/context/` — публичные профили и структурированные источники.

Общие стили: `assets/editorial.css`. Мобильная навигация: `assets/editorial.js`. Подробности реализованы через нативный `<details>` и доступны без JavaScript. Старая таблица стилей сохранена для совместимости, но новые страницы её не подключают.

## Локальный просмотр

В корне проекта выполните:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Не открывайте HTML как `file://`: сайт использует пути от корня домена.

## Проверки

```sh
bash scripts/validate-seo.sh
```

Валидатор проверяет пять русскоязычных страниц, локальные ссылки и якоря, наличие кейсов и профессионального пути, фотографию, синхронизацию JSON-LD, карту сайта и границы языковых версий. Исторические даты не следует заменять годом обновления сайта.

## Публикация

Существующий workflow GitHub Pages публикует ветку `main`. Дизайн в отдельной ветке не меняет работающий сайт до слияния. Страницы и общие ресурсы нужно переносить вместе.
