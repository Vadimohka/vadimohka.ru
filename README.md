# vadimohka.ru

Личный сайт Вадима Владымцева. Статические HTML, CSS и JavaScript; публикация из `main` через GitHub Pages.

## Структура

- `index.html` — главная.
- `background/`, `projects/`, `approach/`, `context/` — путь, проекты, подход и материалы.
- `assets/` — действующие стили, скрипт навигации и утверждённый портрет.
- `favicon.ico`, `favicon.svg`, `apple-touch-icon.png` — иконки.
- `llm/` — текстовые HTML-версии пяти страниц.
- `index.html.md` рядом с каждой основной страницей — её Markdown-версия.
- `llms.txt`, `llms-full.txt`, `*/llms.txt`, `person.jsonld`, `llm-profile.json`, `sitemap.xml` — навигация и данные для поиска.
- `scripts/` — генерация альтернативных форматов, проверки и исходный авторский текст.
- `en/` — совместимость старых адресов английской версии. Не удалять.
- `CNAME`, `.nojekyll`, `robots.txt`, `yandex_98b0fe03a0ad0233.html` — настройки публикации и подтверждение сайта.

## Изменение содержания

Редактируйте основные HTML-страницы. Авторский текст страницы «Подход» хранится в `scripts/content/approach.md`; проверка сверяет с ним текст, ссылки и метаданные. Правила редактуры — в [scripts/COPY.md](scripts/COPY.md).

После правок из корня репозитория выполните:

```sh
python3 scripts/sync-discovery.py --write
bash scripts/validate-seo.sh
```

Скрипты используют стандартную библиотеку Python 3.10 или новее. Генератор обновляет метаданные, Markdown, LLM-страницы, индексы и sitemap. Он не переписывает видимый текст основных страниц. `dateModified` берётся из JSON-LD страницы: меняйте его при содержательной правке, а не при каждой сборке.

Альтернативные представления должны быть закоммичены вместе с исходными страницами. Их нельзя удалять как дубликаты: они публикуются на сайте. Проверка `--check` выявляет расхождения с исходными HTML.

Для локального просмотра:

```sh
python3 -m http.server 8000
```

## Публикация и обслуживание

`.github/workflows/static.yml` выполняет проверки, собирает `dist`, публикует сайт и сравнивает ключевые файлы с работающим доменом. `.github/workflows/seo.yml` проверяет изменения в ветках и pull request.

В `assets/` оставляйте только используемые ресурсы. Перед удалением проверяйте ссылки в HTML, CSS, JavaScript, структурированных данных и скриптах. Сохраняйте основной портрет `assets/hero-vadim-2026.webp` без замены или повторного сжатия.

Не коммитьте кэши, локальные окружения, отчёты браузерных проверок и каталоги сборки. `.gitignore` содержит правила для этих файлов. Устаревшие версии доступны в истории Git; архивные теги прежних рабочих веток не являются действующими ветками.
