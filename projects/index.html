01 / Проект

Century

CTO / R&D Lead · StackLevel Group

centuryENTERPRISE AIВнутри вашего контура.

Задача

Безопасное внедрение LLM в контур бизнеса и государственных организаций.

Реализация

Century — платформа для безопасного внедрения LLM в контур бизнеса и государственных организаций: локально (air-gapped/on-prem) с совместимостью с облачными моделями и единым конвейером для запуска LLM-приложений.

Технические детали и вклад
  • Ядро безопасности и развертывания: Docker/VM, работа «в периметре», OpenAI-совместимый API для RAG интеграций.
  • Ядро точности: гибридный RAG-движок и ответы с верификацией источников (цитата/фрагмент документа или таблицы).
  • Контроль и управляемость: UI для загрузки/тестирования, логирование запросов и ответов, аудит, A/B-тестирование и наблюдаемость.
  • Мультиагентный оркестратор Plan-Execute-Verify для снижения ошибок и ускорения вывода сервисов в продакшен.
  • Отмечено на форуме IT Академград: Century получила диплом 3 степени в категории "AI Product Leader".

02 / Проект

Корпоративная база знаний

AI Solutions Architect

Знания компании
Ответ. С источником. [1]

Задача

Поиск и извлечение информации по внутренним знаниям компании.

Реализация

Разработка корпоративной системы управления знаниями с использованием гибридного поиска и LLM для извлечения информации.

Технические детали и вклад
  • Интеграция Elasticsearch и dense vector search для гибридного поиска.
  • Реализация механизмов верификации источников и цитирования.
  • Разработка пользовательского интерфейса для управления базой знаний.

Прототип рекомендательной системы на базе LLM для персонализации покупательского опыта.
